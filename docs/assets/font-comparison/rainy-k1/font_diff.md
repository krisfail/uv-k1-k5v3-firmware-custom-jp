# 日本語大字形のrainy参照比較

Cソースの指定した対応付けに従い，参照側と現行側の14-byte大字形を比較した結果です．
このレポートは比較用であり，参照フォントをファームウェアへコピーしたことを意味しません．

- 比較範囲: `0x80`–`0xDF`
- 参照ソース: font.c
- 現行ソース: japanese_font.c
- 参照の対応付け: `gFontBig`連続配列を`0x21`起点で順序対応
- 現行の対応付け: コード注釈／指定初期化子
- コード数: 96（一致 7，差分 89，参照のみ 0，現行のみ 0）
- 差分: 886 byte，2151 bit（参照のみ 995 bit，現行のみ 1156 bit）
- ソース上の要素: 両方 89，参照のみ 7，現行のみ 0，両方なし 0（空白要素も比較）
