# WebSerial host tool

WebSerial host toolは，ブラウザーからUV-K1／UV-K5 V3の受信専用ファームウェアへ接続し，メモリー，チャンネル，設定，日本語リソースを扱うための操作画面です．Python版の試作・デバッグ用ツールとは別の静的Webアプリとして配置しています．

## 使用条件

- WebSerialに対応するChromeまたはEdgeを使用する．
- GitHub PagesなどのHTTPSページ，またはローカルHTTPサーバーから開く．`file:`で直接開かない．
- USB接続とプログラミングケーブルを確認してから，画面の「ポートを選ぶ」で対象を許可する．
- 書き込み前に電源断やケーブル抜去が起きない状態を確保する．

## 機能

### メモリー編集

領域プリセットは次のとおりです．オフセットと長さを変更して任意の読み出し範囲を確認できますが，書き込み可能範囲はファームウェアが定める範囲に限られます．

| 領域 | 論理アドレス | 操作 |
| --- | ---: | --- |
| 通常チャンネル | `0x0000–0x886F` | 読み出し・書き込み |
| 拡張設定 | `0x9000–0x90E7` | 読み出し・書き込み |
| 設定 | `0xA000–0xA16F` | 読み出し・書き込み |
| 校正 | `0xB000–0xB1FF` | 読み出しのみ |

編集内容は変更したバイト数と変更したブロック数で確認できます．書き込み時は変更部分だけを転送し，各ブロックの読み戻し結果を検証します．校正領域や上記以外の範囲へ書き込む操作は受け付けません．

### チャンネルと設定

チャンネル一覧は1024件を表形式で編集し，TSVとして読み書きできます．日本語名は外部名前テーブル，ASCII別名は通常チャンネル領域へ保存します．書き込み時にはRX-onlyの境界に従い，送信周波数を保存しません．

設定画面では既知の項目だけを編集し，未定義byteを保持します．設定領域のraw表示は確認用であり，直接編集するものではありません．

### 日本語リソース

同梱フォントと1024件の名前テーブルを個別に読み書きできます．ファイルの内容，文字コード，サイズ，フォント収録文字は書き込み前に検証します．

## ローカルで確認する

リポジトリのルートで次のようにHTTPサーバーを起動し，ブラウザーで`http://localhost:8000/tools/webui/`を開きます．

```text
python -m http.server 8000
```

GitHub Pagesでは`/host/`に配置されます．ページ生成時にフォント台帳のパスもPages用へ調整されます．

## 対応範囲

この画面の静的検査とホスト側のプロトコルテストは，実機での書き込み成功，外部Flashの状態，LCD表示，無線動作を保証しません．実機で書き込む場合は，対象ファームウェアとバックアップを確認し，失敗時に復旧できる状態で操作してください．
