# K1／K5 V3版 実機テスト計画

対象はPY32F071搭載のUV-K1／UV-K5 V3向け`wrx-jp`です．ホストテストやビルド成功だけでは，RF性能，LCDの見え方，書き込み成功を保証できません．試験前に，個体のEEPROM・calibration・全イメージを保存してください．日本語リソースは専用host toolの明示的な書込み操作で確認します．CHIRPは互換・移行用アダプタとして確認し，通常のMemory Uploadへフォント転送を内包する経路は使用しません．

## 試験項目

| ID | 操作 | 期待結果 | 実測・判定 |
| --- | --- | --- | --- |
| SAFE-01 | バックアップを取得し，復元手順を確認する | EEPROM，calibration，全イメージを復元できる | |
| ID-01 | 起動画面とバージョンを確認する | `JP RX-Only`，`Kris`，上流版＋Jパッチ版が表示される | |
| UI-01 | MESSAGE／ALLと画像→メッセージ表示を確認する | `JP RX-ONLY`が崩れず，画像とASCIIメッセージが選択どおり切り替わる | |
| UI-02 | メニュー，ヘルプ，受信画面，チャンネル名を表示する | 固定UIのASCIIが崩れず，外部16×16／8×8縮小／ASCII別名のチャンネル名で基線，点灯範囲，右端の切れ，名前と周波数の重なりが許容範囲に収まる | |
| UI-03 | メニューを開き，左右キーでカテゴリを切り替え，`MENU`で項目一覧へ入り，`EXIT`でランチャーへ戻る | Dondji風ランチャーのアイコンとカテゴリ名が対応し，カテゴリ内の項目数・選択位置・復帰先が崩れない | |
| RX-01 | PTTを短押し・長押しする | 送信せず，モニターだけが切り替わる | |
| RX-02 | 送信要求に相当する操作を行う | ビープ音と`RX ONLY`を表示し，送信波が出ない | |
| RX-03 | FM，NFM，AM，RXExtを切り替える | 各モードで受信音と表示が対応する | |
| BW-01 | 受信帯域を切り替える | 表示，受信動作，保存・復元が対応する | |
| STEP-01 | 周波数ステップを変更し，上下キーで移動する | 設定した刻みで周波数が変化し，保存・復元できる | |
| FM-01 | FM放送帯の76.0，76.1，94.9，95.0 MHzを入力する | 日本向け範囲と端点の扱いが一貫し，10 kHz刻みで選局できる | |
| FM-02 | 既知のFM局を複数受信する | 受信音，帯域，ミュート動作が安定する | |
| SCAN-01 | バンドプリセット，範囲スキャン，スキャン一時スキップを実行する | 指定範囲だけを走査し，停止・再開・スキップができる | |
| SQL-01 | 無信号，弱信号，強信号でスケルチを確認する | 開閉が極端に不安定でなく，逆CTCSSも意図どおり | |
| AUDIO-01 | 受信音声プロファイルを切り替える | 音量，音質，プロファイル表示が対応し，受信を妨げない | |
| AUDIO-02 | 音声スコープ，RSSI，音声レベルを確認する | 表示更新が崩れず，走査・受信を阻害しない | |
| MEM-01 | チャンネル名，バンク，プリセットを保存して再起動する | 設定が保持され，対象チャンネルが正しい | |
| JP-01 | 外部Flashの容量・JEDEC IDとフォントデータ／名前テーブル領域を確認する | 0x020000–0x03EAA4と0x040000–0x048000が既存領域と衝突しない | |
| JP-02 | 専用host toolの「日本語リソース書込み」で日本語名、ASCII名、かな、JIS第1水準漢字、記号を1024件の範囲で書き込み、再読出しする | フォントデータと名前がreadback一致し、既存ASCII名も保持される | |
| JP-03 | 日本語名を表示した状態で再起動し、MDF_NAME／MDF_NAME_FREQ、scan、dual watchを確認する | 単一VFOでは16×16字形と大字形周波数が重ならず、デュアルVFOでは設定にかかわらず8×8名・小字形周波数へ切り替わる。欧文との基線、表示幅、超過名の拒否も確認する | |
| JP-04 | 「主画面チャンネル名」を16×16、8×8縮小、ASCIIで切り替え、MDF_NAME／MDF_NAME_FREQを確認する | 8×8では同じ外部字形が2×2縮小で表示され、ASCIIでは外部字形を使わず`ascii_name`を表示する。単一VFOは収まる限り大字形、デュアルVFOは小字形とし、別名がなければチャンネル番号へ戻る。メニュー表示は変化しない | |
| LOGO-01 | 起動画面の画像，MESSAGE／ALL，`LOGO+MSG`／`LOGO+ALL`の画面切替を確認する | `LOGO+MSG`でロゴ画面の後に`JP RX-ONLY`へ，`LOGO+ALL`で版表示付きの`ALL`画面へ切り替わり，文字列と画像が重ならず，表示が欠けない | |
| CHIRP-01 | 移行用CHIRP互換アダプタで読み取りだけを行い，事前バックアップと比較する | 通常領域だけが読め，calibrationは変化しない | |
| CHIRP-02 | 移行用CHIRP互換アダプタで変更を1件だけアップロードし，再読取する | 変更対象だけ反映し，calibrationが不変 | |
| HOST-01 | 専用host toolのメモリー画面で変更を1件だけ書き込み，再読取・再起動する | 変更対象だけ反映し，calibrationが不変 | |
| HOST-02 | 専用host toolの日本語リソース画面で日本語名を1件設定し，書込み後に再読取・再起動する | 外部Flashのフォントと名前テーブルが書き込まれ，日本語名が再起動後も表示される。純正ファームウェアでは転送されず，通常メモリーも部分書込みされない | |
| POWER-01 | スリープ，復帰，電池低下，再起動を確認する | 状態復元と安全表示が説明どおりに動作する | |

## 不具合記録

写真・動画，表示版，操作手順，再現回数，書き込み前バックアップの有無を記録します．送信波の有無は，可能なら外部受信機または測定器でも確認してください．確認できない場合は「未測定」と記載します．
