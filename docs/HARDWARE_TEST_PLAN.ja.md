# K1／K5 V3版 実機テスト計画

対象はPY32F071搭載のUV-K1／UV-K5 V3向け`wrx-jp`です．ホストテストやビルド成功だけでは，RF性能，LCDの見え方，書き込み成功を保証できません．試験前に，個体のEEPROM・calibration・全イメージを保存してください．日本語リソースはWebSerial host toolの明示的な書込み操作で確認し，必要に応じてPython host toolでも同じ境界を確認します．CHIRPは互換・移行用アダプタとして確認し，通常のMemory Uploadへフォント転送を内包する経路は使用しません．

## 表示モード再確認

主画面チャンネル名の表示モードを変更した場合は，16×16，専用14×14，美咲8×8，ASCIIの順に再起動後の表示を確認します．LCDデバッグ版では，外部Flashの名前テーブルに依存しない`receive-jp-name-16`，`receive-jp-name-14`，`receive-jp-name-8`，`receive-jp-name-freq`，`receive-jp-dual-name`を取得し，固定名の字形・基線・表示幅を確認します．

## 不具合記録

写真・動画，表示版，操作手順，再現回数，書き込み前バックアップの有無を記録します．送信波の有無は，可能なら外部受信機または測定器でも確認してください．確認できない場合は「未測定」と記載します．
