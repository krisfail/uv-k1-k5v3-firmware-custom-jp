# K1版 日本語・受信機能の優先度

K1／K5 V3はK5よりフラッシュに余裕がありますが，LCDの表示幅と既存の1 byteフォント形式は共通の制約です．機能は，受信専用としての安全性を維持しながら，表示の理解しやすさを優先して追加します．

この文書は人間の開発者向けの計画・容量判断資料です．利用者向けの機能説明は[README.ja.md](../README.ja.md)，AIエージェント向けの規則は[AGENTS.md](../AGENTS.md)を参照してください．

> 現行の採用・保留・除外の判定は[FEATURE_AUDIT.ja.md](FEATURE_AUDIT.ja.md)へ統合しました．この文書は，追加順と表示・容量判断の経過を残す補足資料です．実機試験は[HARDWARE_TEST_PLAN.ja.md](HARDWARE_TEST_PLAN.ja.md)を使用します．

## 優先度

| 優先度 | 対象 | 方針 |
| --- | --- | --- |
| A | 帯域幅，FM放送，バンドプリセット，スキャン，RXExt | 受信経路と保存形式の互換性を確認しながら維持する |
| A | メニュー名，状態表示，起動画面，ヘルプ | 既存フォントを優先し，短い日本語で意味を明確にする |
| A | 送信系ビルド経路 | CMake入口で強制無効化し，送信系モジュールを登録しない |
| B | 追加漢字，設定値の日本語化 | atlasで重複と空きコードを確認し，LCD幅を実機で確認する |
| B | 受信状態の説明表示 | TX DISABLEなど安全上必要な英字は残し，誤解を招かない範囲で日本語化する |
| C | 大型の新規解析画面 | フラッシュに余裕があっても，走査時間・RAM・視認性を確認してから採用する |

## 今回の整理

- 帯幅，表示，電池校正を既存字形でメニュー化しました．
- 送信出力の`LOW`／`HIGH`表示は受信専用画面から外しました．電池低下・過電圧の安全状態表示は残します．
- TX DISABLEは機能の安全状態を明確にするため英字のまま残しました．
- 送信可能な上流系CMakeプリセットを削除し，利用可能なビルド入口をJpRxOnlyへ統合しました．

新しい字形を追加する場合は，フォント注釈，フォント一覧，atlas編集手順を更新します．文字コードの再利用や校正領域の利用は行いません．
