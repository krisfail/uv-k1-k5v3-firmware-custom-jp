# メニュー文言の編集

メニューの動作と表示文言を分離しています。日本語の表示文言を変更するときは、まず次のファイルを編集してください。

```text
App/ui/menu_text.h
```

## 編集する場所

- `WRX_MENU_LABEL_*`: メニュー一覧に表示するラベル
- `WRX_MENU_HELP_*`: 受信専用メニューの下部ヘルプ
- `#ifdef ENABLE_JAPANESE` 内: 日本語ビルドで使う内部フォントコード
- `#else` 内: 日本語機能を無効にした比較ビルドのラベル

メニューの順序、項目ID、設定処理は `App/ui/menu.c` に残しています。文言だけを変える場合は、`menu.c` の条件分岐や処理を編集しないでください。

## 制約

通常のメニュー欄は6バイト幅です。終端のNULを含めて7バイトの配列に格納するため、ASCIIなら最大6文字、日本語内部コードも表示上6文字相当以内に収めます。UTF-8の日本語文字列を直接書かず、`App/japanese_font.c` の割り当てに対応する内部コードを使ってください。

ヘルプ文は表示幅に合わせて自動スクロールします。意味が変わる文言を変更した場合は、受信専用メニューの実機表示で、改行・スクロール・既存の画面要素との重なりを確認してください。

## 変更後の確認

```powershell
cmake --build --preset JpRxOnly -j2
python -m unittest discover -s tests -p "test_*.py" -v
```

ビルドは内部コードの構文と配列幅を検証します。LCD上での読みやすさ、字形の割当て、メニューの意味が適切かどうかは実機で確認してください。
