# メニュー文言の編集

メニューの動作と表示文言を分離しています。日本語の調整は次の翻訳ファイルを編集してください。

```text
App/ui/menu_text_ja.h
```

## 編集する場所

- `WRX_JA_MENU_LABEL_*`: メニュー一覧に表示する日本語ラベル
- `WRX_MENU_LABEL_*` の第2要素: フォント未書込み時のASCIIフォールバック
- `WRX_JA_MENU_CATEGORY_*`: カテゴリ名
- `WRX_JA_MENU_VALUE_*`: 設定画面に表示する選択値
- `WRX_JA_ACTION_*`: サイドキー操作の選択肢
- `WRX_MENU_HELP_*`: 受信専用メニューの下部ヘルプ。日本語は `menu_text_ja.h`、ASCIIフォールバックは `menu_text.h` にあります

メニューの順序、項目ID、設定処理は `App/ui/menu.c` にあります。設定値の対応関係は共有配列に影響させず、表示時に `UI_MENU_LocalizeValue` が変換します。文言だけを変える場合は、`menu.c` の条件分岐や処理を編集しないでください。

## 制約

メニュー項目と選択値は日本語を主表示とし、外部フォントが未書込みの場合だけASCII表記へ戻します。16×16字形で48pxの項目欄に収まらない日本語ラベルは、外部の美咲8×8字形へ自動的に切り替えます。画面上で意味が明確な無線方式名・単位・型番はASCII表記を残せます。翻訳は意味を保った短い表現にし、同じカテゴリ内で似た設定を区別できる名称を選んでください。

ヘルプ文は表示幅に合わせて自動スクロールします。意味が変わる文言を変更した場合は、受信専用メニューの実機表示で、改行・スクロール・既存の画面要素との重なりを確認してください。

## 変更後の確認

```powershell
cmake --build --preset JpRxOnly -j2
python -m unittest discover -s tests -p "test_*.py" -v
```

ビルドは内部コードの構文と配列幅を検証します。LCD上での読みやすさ、字形の割当て、メニューの意味が適切かどうかは実機で確認してください。
