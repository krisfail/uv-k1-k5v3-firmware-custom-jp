# rainy版との日本語大字形比較

この文書は，`rainy-knight/uv-k5-jp`の公開ソースを参照側として，現行の日本語大字形をソースレベルで比較した記録です．比較結果は字形の一致・差分を示すものであり，参照側のデータをファームウェアへ取り込んだことや，実機表示が同じであることを示すものではありません．

## 比較対象

- 参照側: `rainy-knight/uv-k5-jp`の`font.c`（Apache License 2.0）
- K5現行側: `font.c`
- K1現行側: `App/japanese_font.c`
- 対象: ソース中の14-byte，2ページ形式の大字形初期化子
- 範囲: `0x80`–`0xDF`

比較処理は，コードコメントまたは指定初期化子に付いたコード値を使う方式と，名前付き連続配列を先頭コードから位置対応する方式を持ちます．rainy版のアクティブな`gFontBig`は後者で，配列の先頭を`0x21`（`!`）として対応付けます．これにより，`0xA1`などの古いコメントが実際の配列位置とずれている部分も，コメントではなく実データの位置で比較できます．小字形の6-byte配列は対象外です．参照データは読み取り専用で扱い，現行ソースを書き換えません．

## 全コードポイントを含む結果

現行のK1比較は，`0x80`–`0xDF`の96コードポイントをすべて出力します．字形が空白であっても，14 byteのゼロ列として比較するため，一致している空白も一覧から抜けません．ソース側に初期化子が省略されている場合は，状態とは別に「ソース上の要素」へ記録します．

生成時点のK1結果は，完全一致7字，差分89字です．一致7字はいずれも空白字形で，rainy版の連続配列にはゼロ初期化子があり，K1側では省略されているため，ソース上の要素は「参照のみ」と表示されます．これは実データの差分ではありません．`0x98=専`／`0x99=用`は，rainy版のその位置が空白で，K1側に字形があるため差分として表示されます．

この結果から，現行配列については「rainy版のバイト列をそのまま使用している」とは扱いません．由来の確認が必要な場合は，ソースの履歴，取り込みパッチ，変換手順を別途確認します．この比較ツールは，その履歴や著作権上の帰属を推定するものではありません．

## コードポイント対応に関する注意

参照側のアクティブな`gFontBig`は`!`（`0x21`）から始まり，実行時には`code - 0x21`で行を選びます．一方，`0xA1`と記されたコメント以降の行は，アクティブ配列上では5コード分後ろへずれています．そのため，コメントだけを使った比較結果を正しいコードポイント対応として扱うことはできません．

基準配列の実データでは，位置対応した`0x98`–`0xA0`の一部が空白です．この範囲はrainy版のコメントが欠けたり古いコード値を示したりするため，生成レポートの文字ラベルは現行側の注釈を優先し，注釈が対応しない参照側コメントは採用しません．`0xA1`–`0xDF`は，連続配列の位置と現行側のコードポイントを比較します．small版の対応表はこの大字形比較には混ぜず，[フォント割り当て台帳](FONT_BITMAP_ANNOTATIONS.ja.md)で別に管理します．

## 比較ツールの使い方

参照リポジトリを任意の作業ディレクトリへ配置し，リポジトリのルートから実行します．パスは公開文書へ出力されません．

K1:

```powershell
python -X utf8 tools/compare_japanese_font.py `
  --reference-source <rainy-repo>\font.c `
  --current-source App\japanese_font.c `
  --reference-array gFontBig `
  --reference-array-start 0x21 `
  --out tmp\rainy-font-comparison-k1
```

出力は次の4ファイルです．

- `font_diff.md`: コードごとの状態とバイト列
- `font_diff.json`: 機械処理用の差分データ
- `font_diff.png`: 一覧画像
- `font_diff.svg`: 重ね合わせ表示（黒=双方，青=参照のみ，赤=現行のみ）

`font_diff.md`と`font_diff.json`には，字形データの状態に加えて，両ソースに初期化子が存在したかどうかも収録します．空白字形の「一致」と，ソース上の初期化子の省略を区別して確認できます．

既存の`tools/font_editor.html`にある編集画面のリアルタイム差分は，この比較とは別の機能です．編集画面では，読み込み時の元データと現在の編集内容を比較します．
