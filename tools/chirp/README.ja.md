# wrx-jp CHIRPドライバ

`wrx_jp.py`は、K1とK5 V3を同じPY32F071プロファイルで扱い、旧UV-K5だけをDP32G030プロファイルで扱う1ファイル構成です。

| CHIRPで選ぶ機種 | 対象ハードウェア |
| --- | --- |
| `UV-K1 / UV-K5 V3 (wrx-jp RX-only)` | UV-K1、UV-K5 V3 |
| `UV-K5 (wrx-jp RX-only)` | 旧UV-K5（DP32G030） |

CHIRPのドライバ配置先へ`wrx_jp.py`をコピーして読み込んでください。機種選択を誤るとメモリーマップが一致しないため、アップロード前に対象機種から全イメージをダウンロードして保存します。

このドライバは受信専用です。CHIRP上では送信周波数、送信トーン、PTT、出力設定を扱いません。FMプリセットは日本向けに`76.0–95.0 MHz`として読み書きします。FM登録数はK1/K5 V3が48件、旧K5が20件です。K1/K5 V3の追加RX機能状態と校正値は、アップロード対象から除外しています。

実機でのCHIRP読み書きは未検証です。バックアップを保持したうえで、まず読み取りだけを確認してください。
